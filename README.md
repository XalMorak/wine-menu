# Wine Menu

QR wine menu — шилийн дээр дарж дэлгэрэнгүй харна.

Виноны цэсийн дижитал хувилбар. Хэрэглэгч QR код сканнар эсвэл шууд холбоосоор нээж, шилийн дээр дарж мэдээлэл харна.

## Онцлог

- QR код үүсгэх
- Шил тус бүрийн дэлгэрэнгүй (нэр, тайлбар, үнэ, зураг)
- Статик сайт — хэн ч хост дээр асан ажиллуулна

## Технологи

Vanilla JavaScript · HTML · CSS

## Хэрхэн ашиглах вэ

1. Сайтыг нээнэ
2. QR код үүсгээд хэвлэнэ / хэрэглэнэ
3. Хэрэглэгч сканнар цэсийг харна
